# Wedding · Никита & Кристина

Стартовый **демонстрационный** проект свадебного сайта и панели подготовки.

> **Важно:** предварительная дата — **17 июня 2027, 14:00, Марьино**. Это **не подтверждённые** данные. Настоящие имена гостей, контакты, приглашения, фотографии, сметы и договоры в репозитории отсутствуют.

## Сейчас есть

- Гостевая версия: главная, программа, информация, список гостей, демонстрационный профиль, будущая галерея.
- Панель организаторов (`#/admin`): обзор, гости, кейтеринг, подрядчики, бюджет, площадки, расписание, задачи, документы.
- Согласованная информационная архитектура и черновая миграция Supabase (`supabase/migrations/001_initial.sql`) с закрытыми по умолчанию таблицами и приватным хранилищем.
- GitHub Actions для размещения **только гостевого демонстрационного фронтенда** на GitHub Pages (файлы исходного прототипа общедоступны, даже если панель не связана с данными).

## Сейчас НЕ реализовано

- Серверная авторизация организаторов и идентификация гостей.
- Реальный список гостей, RSVP, изменение профиля и загрузка фотографий.
- Редактирование кейтеринга, бюджета, задач, документов в админке.
- Защищённое хранение и выдача снимков гостям, модерация, рассылка приглашений.

**Нельзя вводить настоящие персональные данные в текущую демоверсию.** Доступ к `#/admin` пока не защищён, потому что там нет никаких настоящих данных: это только макет интерфейса. Перед эксплуатацией требуется реальный backend и контроль доступа на сервере.

## Запуск без установки зависимостей

```bash
npm run dev
```

Откройте `http://localhost:4173`. Панель организаторов: `http://localhost:4173/#/admin`.

Проверки:

```bash
npm run check
```

## GitHub Pages

После создания репозитория `nkuchenov-hash/wedding-nikita-kristina` загрузите файлы в `main`, затем в `Settings → Pages` выберите **Source: GitHub Actions**. Workflow `.github/workflows/pages.yml` опубликует статическую демоверсию. До настройки реальной авторизации никаких приватных данных в сайт не добавлять.

Будущий адрес при успешной публикации: `https://nkuchenov-hash.github.io/wedding-nikita-kristina/`. **Публикация ещё не подтверждена.**

## Архитектура

Это нулевая версия без внешних зависимостей, чтобы можно было мгновенно открыть и проверить страницы. Для полноценного продукта предусмотрены Supabase (Postgres + Auth + Storage + Edge Functions), закрытые данные и постоянная админка. При масштабировании UI можно перевести на React + TypeScript; структуру данных и адреса страниц это не меняет.
## Визуальный прототип от 28.10.2026

- Главная — полноэкранный слот фотографии пары, композиция с крупной типографикой и многослойной заглушкой парка/колонн Марьино.
- Палитра: лесной зелёный `#214D31`, зелень парка `#4C8C46`, свежая трава `#83B96B`, бело-серый колонн `#E2E4E1`, сохранённое первоначальное золото `#C1A46C`. Жёлтые, кремовые и искусственно состаренные фоны исключены.
- Постоянная нижняя панель навигации с пиктограммами на телефоне и компьютере.
- Заглушка поддерживает лёгкий параллакс слоёв при перемещении мыши. Это пока **не** полноценное пространственное фото iPhone: для реального эффекта потребуется фотография пары и подготовленные слои/карта глубины.
- Для замены заглушки указать одобренную публичную фотографию в `src/data.js` как `heroPhotoUrl`; опциональный прозрачный передний план — `heroSubjectUrl`. Нельзя добавлять личные фотографии без разрешения пары.
- Гостевые экраны, демонстрационная админка и ограничения по безопасности сохранены.
- Автопубликация должна быть включена в GitHub → Settings → Pages → Build and deployment → Source: GitHub Actions. Без этого работа над репозиторием сохраняется, но сайт не публикуется.
